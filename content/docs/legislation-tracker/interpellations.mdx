---
title: Interpellations and questions
description: Find Sejm interpellations and written questions, read the official replies, and track questions that await an answer.
---

The **Interpellations** tab lists interpellations and written questions submitted by members of the Sejm, together with the replies of the addressed authorities.

## Question list

The table shows **Title**, **Type** (**Interpellation** or **Written question**), **Replies**, **Status**, **Received**, and **Answered** (the date of the latest reply). The status is one of:

* **Answered** — the question has been answered;
* **Awaiting reply** — the question is waiting for an answer;
* **Reply overdue** — the reply deadline has passed;
* **Received** — the question has been received by the Sejm.

Select a row to open the question.

## Filters

* **Search questions** — text search, for example *oversight of a public institute*.
* **Term** — the Sejm term.
* **Type** — interpellations or written questions.
* **Status** — one of the statuses above.
* **Recipient** — the addressed authority, for example a ministry.
* **Attributes** → **Answered only** — a shortcut for answered questions; it applies only when no specific **Status** is selected.

A select filter appears only when the data contains values for it. The **Short titles** and **Pin tracked questions** switches and the **Clear filters** action are described in [Legislation](/legislation-tracker).

## Question page

The banner shows the title and the status. The page is divided into sections:

* **Summary** — an automated, plain-language summary of the question and its context. While it is being generated, **Summary is being prepared** is shown and the official text remains available below.
* **Questions asked** — the individual questions extracted from the text, numbered. While the list is being prepared, **Questions are being extracted** is shown.
* **Original interpellation text** or **Original written question text** — the official text with a link to its source. **Official text unavailable** means the Sejm has not published it yet.
* **Official replies** — substantive answers (**Official answer**) and deadline extensions (**Deadline extension**) shown separately, each with its author, date, text, and official attachments. Answers are expanded and extensions collapsed; select the header of a reply to expand or collapse it. **Open official reply ↗** opens the reply on the source site. An unusually long reply is shortened, with a note pointing to the complete official text. **No official answer yet** means the record contains no answer or extension.
* **Status timeline** — the receipt of the question and each reply or extension, in date order.

The side panel contains:

* **Actions** — **Track this question** (or **See alert** once tracked) and **View on sejm.gov.pl**.
* **Details** — **Kind**, **Number**, **Term**, **Status**, the dates **Received** and **Sent**, the reply **Delay**, the number of **Answers** and **Extensions**, and the **Latest event**.
* **Authors & recipients** — the authors link to their stakeholder profiles. For a ministry, the recipient shows the current office holder when known.

An Advisor citation of a specific reply opens the question and scrolls to that reply.

## Empty and error states

* **No questions found** — no question matches the search or filters; change them.
* **Couldn't load questions** — the list could not be retrieved; reload the page.
* **Question not found** — the link no longer resolves; return to the list.
