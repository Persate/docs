**Legislation Tracker** provides access to the legislative process: published legal acts, drafts handled by the Government Legislation Centre, and parliamentary interpellations and questions.

Open the module from **PUBLIC → Legislation** in the sidebar.

## Tabs

Three tabs are available in the top bar of the view:

* **Published acts** — a browser of published acts organized by source (publication journals).
* **Process** — legislative drafts handled in the RCL.
* **Interpellations** — parliamentary interpellations and questions.

## Published acts

The view presents the publication sources in a tile layout. The sidebar provides a **Search sources** field to find a specific journal. Selecting a tile opens the list of documents for that source, and selecting a document opens its detailed view.

## Ministries and offices

The source picker also includes a **Ministries and offices** group. Selecting an institution opens its publications, with filters for text, category and publication date. Recruitment and procurement notices are hidden by default; **Show all categories** makes them available.

Selecting a publication opens its text and attached files. Select a file to read it, or use **Open the source page** to visit the publisher's page. Institution profiles also show **Latest publications**, linking to the same reader. Source content retains its original language.

Alerts for these publications omit recruitment and procurement unless the alert explicitly requests those categories. For example: *Recruitment notices published by this institution*.

## Process

The **Process** tab presents RCL legislative drafts as a table. Filters are available in the sidebar, including:

* **Search** — search by draft title.
* **Work register number** — the number in the work register.
* **Document type** and **Applicant** — the document type and the applicant.
* **Progress** — the stage of the process.
* **Created from / to** — the creation date range.
* additional toggles (including drafts implementing EU law).

The list loads further entries as it is scrolled.

## Interpellations

The **Interpellations** tab presents parliamentary interpellations and questions as a table. The sidebar provides filters, including search by title, term (**Term**), kind (**Kind**), status, ministry (**Ministry**), and an **answered** shortcut.

## Empty view and error states

* *"No matching sources"* — no source matches the search.
* *"No projects found"* / *"No questions found"* — no entry matches the current filters. Change the search or filters.
* *"Couldn't load projects"* / *"Couldn't load questions"* — a connection error with the service. Retrying is recommended.
