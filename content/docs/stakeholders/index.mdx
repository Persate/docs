**Stakeholders** is a catalog of parliamentarians integrated with data regarding their legislative and media activity. Every profile combines biographical materials, parliamentary club affiliation, voting records, and parliamentary speeches.

Access to the module is provided by the **KNOWLEDGE BASE** group in the sidebar, under the **Stakeholders** and **Public Pulse** entries.

## Relationship between views

The platform tracks two related data streams:

* **Stakeholder catalog** — an identity database of monitored individuals. Selecting a stakeholder card opens their full profile.
* **Public Pulse** — an activity stream on the X platform assigned to individuals from the catalog. Filters in this view use the same metadata (e.g., club affiliation) as the main catalog.

## Catalog overview

The catalog presents a list of stakeholders in card format.

### Stakeholder card

Every card contains:

* **Party banner** — a background generated based on parliamentary club affiliation.
* **Name** and profile picture.
* **Contact information** — email address and basic professional information.
* **Electoral indicators** — number of received votes (**Votes**) and district number (**District**).

Selecting a card opens the detailed stakeholder profile.

## Filtering and sorting

View management tools are available in the sidebar:

* **Search** — filtering the list by first and last names (minimum 2 characters required).
* **Club** — restricting the list to members of selected political groups.
* **Sorting** — ordering by last name (**Last Name**) or number of received votes (**Votes**).

## Empty view and error states

* *„No stakeholders match your filters"* — active filters exclude all entries. Changing the search criteria is recommended.
* *„No stakeholders available"* — the system has not retrieved data from the legislative service.
* *„Couldn't load stakeholders"* — server connection error. Refreshing the page is recommended.
