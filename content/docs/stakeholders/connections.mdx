---
title: Connections
description: Build and inspect an evidence-backed graph of people, organizations, legislation, and topics.
---

Open **PUBLIC → Stakeholders**, then select the **Connections** tab. Connections is an exploratory workspace: it researches a described subject and presents related entities in an interactive graph.

## Start a graph

Describe a topic, person, organization, or legislative matter. Specific names and identifiers produce a more focused result than a broad abstract topic. When submitted, Persate researches the subject, groups the result into thematic clusters, and retains supporting source fragments when available.

Keep the page open while research is running. A generated connection is a research aid, not proof by itself; inspect the cited evidence before using a relationship in a briefing.

## Read the graph

* Node color distinguishes entity types such as people, organizations, legislation, and keywords.
* Node size indicates relative connectivity or mentions in this generated result.
* Edges represent relationships found within the researched context.
* **Clusters** explains the identified themes and why entities matter.
* **Sources** lists supporting fragments when the research result includes them.

The graph reflects this research run and its available sources. It is not a complete register of every legal, financial, or personal relationship.

## Interact with the result

Pan and zoom the canvas or fit the graph to the view. Select a node to inspect its role and rationale. Canonical entities can provide a link to their Stakeholder profile.

Removing a node hides it from the current view; it does not delete the underlying public record. Use the restore action to bring hidden nodes back.

## Refine or save

After generation, use the review controls to:

* save the graph as a draft for later review;
* refine it by narrowing or widening the scope, requesting sources, or reducing noise;
* discard it and return to the starting state.

## Troubleshooting

* Sparse graph — use a more specific subject or identifier and request the missing relationship explicitly.
* No Sources section — the result did not return supporting fragments; do not treat uncited edges as verified facts.
* Profile link absent — the node is not linked to a canonical Stakeholder record.
* Generation failed — retry once with a shorter, more specific request.
