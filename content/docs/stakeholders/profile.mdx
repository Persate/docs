---
title: Stakeholder profile
description: Detailed stakeholder view — a biography broken down by source, contact data, attendance, and legislative activity.
---

The **Stakeholder profile** contains a complete set of information about a given entity. The profile is accessed by selecting an entry from the **Stakeholders** list.

## Title card

The upper part of the profile presents the stakeholder's identity:

* **Banner** — a procedurally generated background based on club affiliation (with the group's logo, if available).
* **Picture and name** — the primary profile label.
* **Role row** — the function held along with its context (club or institution).
* **Create alert** — for stakeholder profiles, the button allows creating an alert that tracks a given individual or entity; when an alert already exists, the button opens it (**Open alert**).

## Biography and profile sections

The left column presents the profile as generated thematic sections (among others **Summary**, **Biography**, **Education**, **Professional career**, **Political career**, **Current mandate**, **Political positions**, **Voting record**, **Public statements**, **Affiliations & interests**, **Finances**). For longer profiles, a sticky table of contents is displayed on the left to aid navigation.

Each section may contain references to sources (e.g., **Sejm RP**, **Wikipedia**, **Wikidata**, **mamprawowiedziec.pl**, **Editorial**). Below the content, an expandable **Show raw sources** section is available, presenting the source data fragments with their origin marked.

## Contact data and statistics

The right column contains:

* **Contact & details** — role, institution, profession, education, date and place of birth, voivodeship, district, number of votes received, email, and a link to the source. Missing fields are marked in italics as *None*. Below is an **Online presence** section with links to external profiles (X, Facebook, Instagram, website, Wikipedia, mamprawowiedziec.pl).
* **Voting activity** — an attendance ring along with the number of votes cast and absences. The section is hidden when statistics are not available.

## Conditional sections

Below, if the data is available, additional sections are presented:

* **Campaign Promises** — campaign promises along with tags and links to sources.
* **Financial Disclosures** — asset declarations broken down by period and category (cash assets, real estate, income, movable property, liabilities, shares and stocks).

## Empty view and error states

* *"Profile not analyzed yet"* — the profile has not been analyzed yet; generated sections will appear after analysis.
* *"No profile details"* — no biographical data for the given entity.
* *"Not found"* — the stakeholder record does not exist at the specified address. Returning to the main list is recommended.
