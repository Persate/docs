title: Stakeholder profile
description: Detailed view of a single stakeholder — personal data, biography, voting activity, and recordings.
---

The **Stakeholder profile** contains a complete set of information about a given individual. The screen consists of a title card, statistics tiles, and a tabbed content area.

Access to the profile is obtained by selecting a card from the **Stakeholders** list.

## Title card

The upper part of the profile presents the stakeholder's identity:

* **Party banner** — a color background consistent with parliamentary club affiliation.
* **Name** — the primary profile label.
* **Affiliation row** — information about Sejm membership and parliamentary club affiliation.

## Key statistics

Statistics tiles with numerical data are located below the title card:

* **Votes received** — the number of votes obtained in elections.
* **District** and **Voivodeship** — the electoral district and voivodeship.
* **Attendance** — the percentage of participation in plenary votes.

## Profile sections (Tabs)

Data is grouped into thematic tabs:

### Overview

The default section containing biography and contact information. Below the biography, a **Show raw sources** section is available, displaying source data fragments. When no contact information is available (e.g., email), the italic *None* is displayed.

### Voting activity

A card presenting an attendance ring and the absolute count of cast votes and absences. The section is hidden when statistics are not available.

### X

The stakeholder's post stream on X. When no linked account exists, the message *„No X account on file"* is displayed.

### Recordings

A list of analyzed Sejm recordings in which the stakeholder was identified. Selecting an entry opens the **Live proceedings** view with the option to play back the fragment.

### Personal details

A compilation of contact information and links to external profiles presented as a clear card.

## Features in development

The following sections are visible in the interface but currently remain unavailable:

* **Promises** — will eventually present electoral promises and policy positions.
* **Financials** — will eventually provide asset declarations broken down by real estate, assets, and income.

## Empty view and error states

* *„No recordings yet"* — the stakeholder has not yet been identified in any processed recordings.
* *„No X account on file"* — no X account has been linked to the profile.
* *„Not found"* — the stakeholder record does not exist at the specified address. Returning to the main list is recommended.
