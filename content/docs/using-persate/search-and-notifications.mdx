## Global search

Open search with **Search** at the top of the sidebar, with the search button in the dock on a phone, or with Ctrl+K (⌘K on a Mac) from any page, and type in **Search the platform...**. Search opens over the dimmed page, with the field near the top. Results start to appear from two characters and update while typing. Some sources need a longer query, so a short query can miss results that a fuller one finds.

Search covers the modules enabled for the organization, and every result respects access to the individual record. Results are grouped into categories:

| Category | What it finds |
|---|---|
| **Files** | Repository files by name; longer queries also match file content |
| **Folders** | Smart Folders |
| **People** | Stakeholders — people and organizations |
| **Related** | Records connected to matching people, institutions and keywords |
| **Alerts** | Tracker alerts |
| **Acts** | Government projects, Sejm prints, legal acts and documents, parliamentary questions, committees and legislative processes |
| **Ministries** | Publications of ministries and other public offices |
| **Live** | Recordings and transcript passages |
| **Votes** | Sejm and Senate votes, decisions of the President and Constitutional Tribunal cases |
| **Media** | Media topics, stories and posts |

The **Go** category lists platform sections, for example *votes* or *open recordings*. An identifier — an ELI, a Sejm print number, an RCL project number, a Constitutional Tribunal case signature or a voting reference — is matched directly and placed at the top of the results. Results can also come from Persate's automated analysis of a source; they appear in the category of the source itself, not in a separate category.

### Reading the results

Results are listed under the search field, one per row. Each row shows the title with its source or key details, the type and the date in aligned columns, and below the title the passage that matches the query, with the matching words in bold. On a phone, the type and date appear under the title. Repository files and alerts also show who can see them.

While sources are answering, placeholder rows stand in for the results, and the line under the category buttons reports the state: **Searching**, how many results have arrived so far, then, once every source has answered, that the results are being ordered by relevance. The order can change at that moment. When it is done, the line shows the number of results, or that nothing was found. **Not answering** lists the sources that did not answer in time; results from the other sources are shown as usual.

### Filtering by category

The category buttons are under the search field before you type, so you can pick a category first. After a search, each button shows how many results the category returned. Select a button to show only that category, and select it again to show every result. A category without matches is greyed out on a large screen and hidden on a smaller one. The selected category is kept when the query changes.

### Previewing a source

**Preview source**, the information icon at the end of a row, opens a preview without leaving search. It shows the source type, the title, the date and details, the source excerpt and, when available, a separate **Source analysis** section, labelled **Automated analysis of this source**, with topics and an explanation. An ordinary search shows no importance assessment. When the query itself asks about importance, for example with *important*, *significant*, *ważne* or *istotne*, the preview can add a qualified label such as **Potentially significant — automated assessment**.

**Back to search** or Escape closes the preview, and **Open source** opens the result. Interface labels follow the selected language; source text keeps its original language.

### Opening a result and coming back

Select a row to open its page. Search closes; a Repository file opens in the file preview over the current page, and a result that points outside Persate opens in a new tab.

Search keeps the last query. Opening it again — for example after reading a result — shows the same query, category and results at the same place in the list, without searching again. After ten minutes it asks the sources again. With the field empty, **Recent searches** lists the latest queries; select one to search it again, remove one with the cross, or clear the list. The list is kept in the current browser only, for the signed-in account.

From the keyboard, the down arrow moves from the search field to the first result, the arrow keys move between results and Enter opens the highlighted one. Escape or a click on the background closes search; on a phone, use **Close search** (the arrow next to the field). On a phone, Enter hides the keyboard; tap a result to open it.

### Asking the Advisor

When the query reads like a question or an instruction, **Ask the Advisor** appears next to the search field. It starts a new Advisor conversation with the query as the first message. Ctrl+Enter (⌘+Enter on a Mac) in the search field does the same.

## Announcements

**Announcements** in the header holds release notes and product news from the Persate team. The counter on the button shows unread announcements.

The panel has two tabs: **Unread**, with the number of unread announcements, and **All**. Each announcement is shown in full; one that links to a page in Persate shows **Open in Persate**. **Mark as read** (the check mark) marks a single announcement, and **Mark all as read** marks every one. **Maximize panel** widens the panel for longer content, and **Restore panel size** returns it to normal.

## Messages

**Messages** in the header holds messages addressed to the account: messages from the Persate team and the notifications switched on in **Settings → Notifications**, such as alert matches or a finished Advisor task. The complete history of an alert's matches stays on the alert's page in Tracker.

The panel has two tabs:

* **Inbox** — current messages, with the number of unread ones. **Mark as read** and **Archive** act on a single message; **Archive all** archives every message shown in the inbox.
* **Archived** — archived messages. **Move to inbox** restores a message.

A message that links to a page in Persate shows **Open in Persate**. **Maximize panel** widens the panel for longer content.

## Notices and connection status

Notices from the Persate team — information, maintenance, delays, warnings or incidents — can appear as bars above the header, either on every page or only within one module. A longer notice shows **Details** to expand its full text. **Dismiss this notice** (the cross) hides it in the current browser; it returns if the notice is updated.

A bar also appears above the header when the browser loses its connection, as content may then be out of date, or when data loads unusually slowly. It disappears on its own when the connection recovers.

## Notification settings

**Settings → Notifications** controls what is delivered:

* **Product updates** — email about new features and release notes.
* **Alert emails** — an email when an enabled alert is triggered.
* **Alert match notifications** and **Advisor notifications** — notifications in Persate and on the phone.
* **Browser notifications** — a notification in this browser when a long Advisor task finishes while another tab is in front.

Alert events remain available on the alert's page even when emails and notifications are off. See [Preferences and notifications](/account-and-settings/preferences) for details.

## Empty and error states

* **All caught up** — there are no unread announcements, or the message inbox is empty.
* **No announcements yet** — the **All** tab has no announcements.
* **Nothing archived** — no message has been archived.
* **Messages couldn't be loaded** — select **Try again**; no message has been changed.
* **No matches** — nothing matched in the enabled categories. Try different wording or a longer query.
* **Search incomplete** or **Some sources unavailable** — some sources did not answer. The results shown remain usable; repeat the query or open the module directly.
