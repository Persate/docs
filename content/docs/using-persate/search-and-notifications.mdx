## Global search

Open **Search** from the platform controls and enter a word, phrase, topic, question or identifier in **Search the platform...**. Results can include legislation, votes, stakeholders, Repository files, Smart Folders, alerts, recordings, Media stories and posts, and Sources. Questions that need a broader explanation also offer **Ask the Advisor**.

On a wide screen, results appear in a cloud around the search field. Existing cards stay in place while further results arrive. Category buttons focus the search on an area; the **Previous results** and **Next results** arrows reveal the remaining retrieved results. On smaller screens or with enlarged text, results appear as compact scrolling rows.

Each result identifies its source. **Preview source** opens a small preview with the source excerpt and any matching **Source analysis** in separate sections. Analysis is labelled as automated and retains its uncertainty and limitations. It belongs to the original source rather than a separate search category. Ordinary searches show no importance assessment; a query explicitly asking about importance may show a qualified assessment inside the preview. **Back to search** or Escape closes the preview, and **Open source** opens the original destination. Interface labels follow the selected language; source text stays in its original language.

Select a result to open its canonical detail page. When a result represents a Repository file, Persate may open the file picker or preview in the current workflow instead of navigating away.

Search providers have different minimum query lengths and filters. If a category returns no result, refine the wording rather than assuming that the underlying module is empty. Results also respect tenant entitlements and record-level access.

## Announcements

**Announcements** contains release and product notices. Opening the feed refreshes it. Individual notices can be marked as read, and **Mark all as read** clears the unread state for the current feed.

## Messages

**Messages** contains direct and system messages, not alert matches. It has two tabs:

* **Inbox** — current messages. A message can be marked as read or archived.
* **Archived** — archived messages. **Move to inbox** restores a message.

Use **Archive all** to archive every loaded inbox message. The panel can be expanded for longer content.

## Alert and report notifications

Open **Settings → Notifications** to control delivery preferences. **Alert emails** are optional e-mail delivery for enabled alerts. Alert events remain available on the alert detail page even when e-mail is off. The navbar inbox is not the alert event history.

Some notification rows are labeled **Coming soon** and cannot be enabled. See [Preferences and notifications](/account-and-settings/preferences) for the current list.

## Empty and error states

* **All caught up** — the inbox contains no messages.
* **Nothing archived** — no messages have been archived.
* **Messages couldn't be loaded** — select **Try again**; no message state has been changed.
* **Some sources unavailable** or **Search incomplete** — some sources could not return results. Available results remain usable; retry the query or open the destination module. A category with no matches may also need a longer or more specific query.
