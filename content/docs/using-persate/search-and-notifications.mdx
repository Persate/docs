## Global search

Open **Search** from the platform controls and enter a query in **Search the platform...**. Results are grouped by the areas that can answer the query, such as legislation, votes, stakeholders, Repository files, Smart Folders, alerts, recordings, Media topics, and Sources.

Select a result to open its canonical detail page. When a result represents a Repository file, Persate may open the file picker or preview in the current workflow instead of navigating away.

Search providers have different minimum query lengths and filters. If a category returns no result, refine the wording rather than assuming that the underlying module is empty. Results also respect tenant entitlements and record-level access.

## Announcements

**Announcements** contains release and product notices. Opening the feed refreshes it. Individual notices can be marked as read, and **Mark all as read** clears the unread state for the current feed.

## Messages

**Messages** contains direct and system messages, not alert matches. It has two tabs:

* **Inbox** — current messages. A message can be marked as read or archived.
* **Archived** — archived messages. **Move to inbox** restores a message.

Use **Archive all** to archive every loaded inbox message. The panel can be expanded for longer content.

## Alert and report notifications

Open **Settings → Notifications** to control delivery preferences. **Alert emails** are optional e-mail delivery for enabled alerts. Alert events remain available on the alert detail page even when e-mail is off. The navbar inbox is not the alert event history.

Some notification rows are labeled **Coming soon** and cannot be enabled. See [Preferences and notifications](/account-and-settings/preferences) for the current list.

## Empty and error states

* **All caught up** — the inbox contains no messages.
* **Nothing archived** — no messages have been archived.
* **Messages couldn't be loaded** — select **Try again**; no message state has been changed.
* A silent search category — the provider may be unavailable or the query may be below its minimum length. Open the destination module to confirm.
