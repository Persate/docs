title: Import and draft
description: Starting an Editor article from a blank page or an imported document.
---

## Create a blank article

1. Open **Editor**.
2. Select **Create article**.
3. Enter or paste the article text.
4. Add a title and format the document with the toolbar.

Persate detects article structure from pasted text. Autosave starts after the article is created.

## Import a document

Select **Import document** from the library or review panel. Editor accepts PDF, DOCX, JPG, JPEG, PNG, and TIFF files.

When the organization also has Repository access, choose one import mode:

* **Save to Repository** — stores the original as a normal Repository file and uses it to create the Editor draft.
* **Use for this document only** — extracts the content for the draft without keeping the upload in the Repository.

The choice can be remembered for later imports. Without Repository access, the temporary mode is selected automatically.

Temporary imports are private. Persate removes the uploaded source after extraction; the Editor article remains. A Repository import follows the audience and retention behavior of the saved Repository file.

## Import processing

The library shows **Importing** while text is extracted. Editor checks the status periodically. Scanned files can take several minutes because the pages must be recognized before the article is ready.

If extraction fails, try another supported PDF, DOCX, or image, or create a blank article and paste the text. Spreadsheet formats accepted by Repository are not Editor import formats.

## Restructure document

**Restructure document** reorganizes headings, paragraphs, and lists without starting the full facts-and-language review.

The action requires at least 80 characters and at least two detected blocks. If review suggestions are still pending, Editor asks for confirmation because restructuring clears those pending annotations. The restructured document can be undone from the editor history.

## Save conflicts

Autosave uses document revisions. If the same article is changed elsewhere, Editor refuses the stale save and displays **This document changed in another tab. Reload**. Copy any unsaved text if needed, reload, and then repeat the edit against the current revision.
