## Create an article

1. Open **WORKSPACE → Editor**.
2. Select **Create article**. A new article named **Untitled document** opens.
3. Select the title to rename the article; **Enter** confirms the new title.
4. Write or paste the text.

## Import a document

An import creates a new article from a PDF, DOCX, JPG, JPEG, PNG or TIFF file. The command sits in the toolbar of an open article:

1. Open an article (or create one) and select **More formatting** (**…**) at the end of the toolbar.
2. Select **Import document** and choose the file.
3. When Repository is enabled for the organization, choose what happens to the uploaded file:
   * **Save to Repository** — the original stays in Repository and remains searchable with other documents;
   * **Use for this document only** — the original file is deleted after its text is extracted.
4. Select **Continue**.

**Remember my choice** skips the question for later imports. The default can be changed in **Settings → Preferences → Editor document uploads** (**Always ask**, **Save to Repository** or **Use for Editor only**). Without Repository, imported files are always used for the article only.

The imported text opens as a separate article; the article from which the import was started does not change. While the text is extracted, the article shows **Reading document…** and the library lists it as **Importing**. A multi-page scan can take a few minutes.

If no text can be extracted, the article shows **The document could not be read.** and the library marks it **Attention**. **New document** returns to the library. Try another PDF, DOCX or image, or paste the text into a new article.

## Drafts prepared by Advisor

In an Advisor conversation, Advisor can prepare an article and save it as an Editor draft. The answer then shows an **Article draft** card with the destination **Editor** and its status: **Preparing draft**, **Draft saved**, **Needs review · Your edits are preserved** or **Preparation interrupted**. Selecting the card opens the draft; Advisor can also open a saved draft directly.

When the draft is opened from the card, the Advisor panel in Editor shows **Draft activity**: the preparation status, the work of Advisor's research agents and an **Original conversation** link back to the chat. If Advisor prepares another version after the draft has been edited, the edits are kept and the new version waits beside them — **Preview proposal** shows its text and **Replace with this proposal** replaces the current text with it. **History** then records the origin as **Draft created by Advisor**.

## Write and format

The toolbar above the text contains:

* the **Text style** menu, which shows the style of the current block: **Paragraph**, **Title**, **Heading**, **Subheading**, **Section heading**, **Minor heading**, **Small heading**, **Quote**, **Bulleted list**, **Numbered list** or **Code block**;
* **Bold**, **Italic**, **Underline**, **Strikethrough**, **Bulleted list**, **Numbered list**, **Quote**, **Add link** (**Edit link** on an existing link), **Undo** and **Redo** — buttons that do not fit move into **More formatting**;
* **More formatting** (**…**) with the document actions **Check document**, **Review options**, **Copy text** and **Import document**, followed by **Inline code**, **Code block**, **Divider** and **Clear formatting**.

**Add link** asks for the web address; an empty address removes the link. Selecting text shows a small toolbar with **Bold**, **Italic**, **Underline**, **Add link** and three Advisor actions described in [Advisor in Editor](/editor/advisor-in-editor).

Markdown shortcuts at the start of a line: `#` to `######` followed by a space create headings, `-` followed by a space starts a bulleted list, `1.` a numbered list and `>` a quote. Plain text pasted with Markdown structure (headings, lists, quotes, code blocks) is converted into formatting; content copied from web pages and word processors keeps the formatting Editor supports. Web addresses typed into the text become links.

On wide screens, an outline of the article's headings appears beside the text; selecting an entry scrolls to that section.

## Autosave and save conflicts

Editor saves changes automatically shortly after typing stops and when the browser window loses focus. There is no save button.

* **Your changes could not be saved.** — select **Retry save**.
* **This document changed in another tab. Reload to continue.** — the article was saved from another tab or device in the meantime. Editing and Advisor stay locked until **Reload**. Before reloading, select and copy any passage that should not be lost.

## Copy the text

**More formatting → Copy text** copies the article body as plain text, with a blank line between paragraphs; the command briefly changes to **Copied**. The title, footnote numbers and the source list are not copied. **Copy text** is the way to take an article out of Editor — there is no file export.
