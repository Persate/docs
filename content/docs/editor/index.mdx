**Editor** is a writing workspace for articles, briefs and statements. The open document sits in the center of the page; a rail on the right switches between the text, its history, its sources and Advisor. Advisor answers questions about the text and proposes edits that change the document only after they are applied. **Check document** reviews facts and language passage by passage.

Editor appears under **WORKSPACE → Editor** when the feature is enabled for the organization. Otherwise the page shows **This feature is not included in your plan**.

## Library

Opening Editor shows the library: a table of the signed-in user's own articles with the **Name**, **Status** and **Updated** columns. Selecting a row opens the article. Articles are not shared with other members of the organization.

The side panel contains:

* **Create article** — creates an empty article named **Untitled document** and opens it;
* **Search** — filters by title, text and imported file name;
* **Status** — **All articles**, **Drafts** or **Reviewed**.

| Status | Meaning |
| :--- | :--- |
| **Importing** | Text is still being read from an imported file. |
| **Draft** | No check of the article has finished yet. |
| **Reviewing** | A check is running. |
| **Reviewed** | At least one check has finished, fully or partly. |
| **Attention** | The imported file could not be read. |

To delete articles, select their checkboxes and choose **Delete selected** in the bar at the bottom of the screen. After confirmation, the saved text, saved reviews and analysis are removed permanently; deletion cannot be undone.

On narrow screens, the side panel opens from the **Articles** button.

## Document workspace

The breadcrumb shows the article title; selecting **Editor** in the breadcrumb returns to the library. The document area holds the editable title, the formatting toolbar and the text. The rail on the right switches views:

| Rail entry | Opens |
| :--- | :--- |
| **Text** | The document. |
| **History** | Recent changes, the document's origin and saved reviews. |
| **Sources** | Numbered references matching the footnotes in the text. |
| **Advisor** | The Advisor panel for the open document. |
| **Plan** | The step plan Advisor shared for the current request; shown only while such a plan exists. |

Side panels — Advisor, Sources and review findings — open beside the text and can be widened by dragging their left edge. On narrow screens, the rail becomes a row of labeled icons above the document and panels open as sheets from the bottom of the screen.

## Typical workflow

1. [Create an article or import a document](/editor/import-and-draft), or let Advisor prepare a draft in a conversation.
2. Write the text and [ask Advisor](/editor/advisor-in-editor) to check, rewrite or extend passages; apply the proposed changes that fit.
3. [Run Check document](/editor/review-and-versions) for facts and language and resolve the review points.
4. Use **History** to see what changed and, if needed, return to a saved review.
5. Select **Copy text** to take the finished article to another tool.

## Limits

* Checks and Advisor requests work on documents of up to 60,000 characters.
* While a check runs, the document is read-only and Advisor is unavailable.
* Editor saves automatically; there is no save button and no file export — **Copy text** copies the article body as plain text.
