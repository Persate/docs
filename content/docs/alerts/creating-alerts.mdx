title: Creating and editing alerts
description: Defining topics for monitoring using the AI advisor and verifying generated rules.

**Creating alerts** enables defining new topics for monitoring using the AI advisor, which automatically builds rules based on a natural language description.

## Defining the topic

The process begins by entering a description of the issue in the **What do you want to monitor?** text field. The platform allows describing the topic in your own words (e.g., a specific bill, person, social issue, or industry trend).

Ready-made suggestions are available below the input field, such as:

* **Law or act** — tracking changes in specific legal acts.
* **Politician or institution** — monitoring the statements and activity of selected politicians.
* **Industry topic** — observing regulatory changes in a specific sector.
* **Societal issue** — tracking discourse around social problems.

## Generation modes

After entering the topic, select one of the two AI advisor modes from the dropdown menu (available after selecting the icon next to the text field):

* **Quick** — a fast mode (approx. 30 seconds) where the platform automatically decomposes the topic and creates an alert without additional web searching or the possibility of deeper refinement.
* **Deep** — an in-depth mode (approx. 120 seconds) where the advisor analyzes the topic, verifies information on the web, prepares examples, and presents a draft for approval or modification.

After selecting the mode, start generation by selecting the send icon on the right side of the text field.

## Draft verification and editing (Deep mode)

When **Deep** mode is selected, the platform presents the generated alert draft. This view contains the title, description, identified subtopics, tags, and test search results.

Below the draft, in the **What would you like to do?** section, determine the next action:

* **Looks good — save it** — approves the draft in its current form.
* A set of predefined options (context-dependent, e.g., splitting into two alerts, narrowing down to specific profiles) — enables rapid alert adjustment according to an intelligent suggestion.
* **Tell me what to change** — a text field allowing the input of custom instructions for the advisor (e.g., removing a specific subtopic).
* **Discard this draft** — rejects the prepared draft and returns to the initial form.

Confirm the selected action using the **Save** button in the bottom right corner.

## Empty view and error states

* *„Not enough data to create alert”* — insufficient data to create an alert; provide more information or try again.
* *„Generation failed”* — server error during alert creation; try again or refresh the page.
