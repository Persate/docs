title: Alert detail
description: Detailed alert view — title banner, trigger event log, and permissions management.
---

The **Detailed view** enables analyzing recorded events and managing the alert's state and visibility. It consists of a title banner, action row, event log, and reference panel.

## Title banner

The banner contains key alert metadata:

* **Name and status** — header with state information: **Active** or **Paused**.
* **Visibility** — designated as **Private** (creator only) or **Shared** (shared within selected groups).
* **Creation date** — timestamp presented next to a clock icon.
* **AI illustration** — a thematic image automatically matched to every alert.

## Action buttons

Buttons enabling state modification are located below the banner:

* **Pause / Resume** — pauses or resumes content monitoring. In the paused state, new events are not recorded.
* **Make Shared / Make Private** — changes the visibility scope. Switching to shared status requires designating at least one user group in the dialog window.
* **Edit** — opens the alert parameter editing form.
* **Delete** — permanently deletes the alert along with its entire event history. The operation requires confirmation and is irreversible.

## Trigger history

The **Trigger History** section contains a chronological log of all matches. Every entry presents:

* **Source** — the type of content where the match was found (e.g., **Sejm speech**, **Public pulse**).
* **Timestamp** — the exact moment the event was detected.
* **Context fragment** — a snippet of the matching content. Longer fragments are automatically truncated; they can be expanded using the **Show more** option.

When no matches exist, the message *„No trigger events yet”* is displayed.

## Permissions panel

For alerts with **Shared** status, the **Shared with** section is available. It enables:

* **Adding groups** — the **Add group** button allows selecting new groups from the list.
* **Removing access** — selecting the **X** icon next to a group name immediately revokes its permission to view the alert.

## Reference bar

The right column contains a sticky card previewing alert parameters: the full description and a list of active keywords. It serves as a reference point while reviewing the event history.

## Empty view and error states

* *„No trigger events yet”* — no matches have been recorded for this alert yet.
* *„Alert not found”* — the record does not exist or permissions to view it are missing. In this case, return to the main list.
* *„Not shared with any groups”* — the alert is shared, but no group is assigned to it. Designating recipients is required for correct operation.
