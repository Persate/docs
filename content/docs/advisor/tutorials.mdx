In **Tutorials**, choose one of the three Advisor lessons. Each points to the real interface and includes English and Polish narration. You can enable, pause or mute the narrator.

The tooltip gives a short hint; narration provides the fuller explanation. The forward arrow below the steps continues a reading step without activating the highlighted control. Practical steps advance after your action, such as opening search; the arrow can skip them. The tutorial does not send your practice questions.

Opening Settings pauses narration. Changing the language there does not restart it. Return to the lesson and use **Resume narration** when ready; your place in the tutorial is preserved.

## Questions, context and skills

Start with the result you need. A useful pattern is: **task + material + period + criterion + output format**.

> Compare two named parties' positions on energy policy in Sejm speeches from the last month. Put the arguments in a table and include quotations with sources.

A short sentence is enough for a simple question. For a larger analysis, identify the people, sitting or document collection and say whether you need a complete set or a sample.

In the lesson, you draft a question, open **+ → Repository**, find a particular law and attach it. **@** opens the same search. If you are still looking for the right document, describe it in your question instead of attaching an arbitrary file.

The Advisor selects its [skills and tools](/en/advisor/skills). You do not need to enable a separate research or visualization mode. **Thinking depth** adjusts how thoroughly it works on the next message. Above an existing answer, expand **Worked for** to inspect the tools and sources used.

After sending, refine the task in the same conversation: “limit this to draft laws,” “compare with the previous period,” or “show a chart.” Check citations before relying on the findings.

## Projects and sharing

1. Click the project name or **No project** below the composer.
2. Choose **New project** and enter a recognizable name.
3. Choose **Private project** or **Shared project**.
4. For a shared project, select the intended group in **Share with**.
5. Review the name and audience, then choose **Create project**.

In the lesson, you practice using the form and close it with **Cancel**. You can save your own project afterwards.

Members of the selected group can **read conversations and analysis documents**. Only a conversation's author can continue it or update its analysis. A project organizes chats; it does not automatically add every other conversation to a question's context.

Move an existing conversation using **… → Move to project**, the project selector below the composer, or drag it onto a folder. Moving a private conversation into a shared project asks you to confirm the audience, because this also shares its existing content.

Change the order by dragging conversations or choosing Move up and Move down in their menu. The change appears immediately. If saving fails, the previous arrangement returns with an error message.

## Plans and research

Choose **+ → Plan** before sending a question when you want to review the proposed steps first. You can ask for changes. **Execute plan** starts the work. An ordinary working plan shows progress without separate approval.

Open the Advisor view with the split-view button, then choose **+ → Plan** or **Analysis document**. These are tabs inside the platform. The main answer stays in chat; the document collects detailed findings, tables, charts, research and sources.

In a study:

- Read the title, scope and legend. Colors describe the current criterion. An unavailable assessment is not a negative result.
- Open the **Study options** gear to switch between **Tiles**, **Comparison** and **List**.
- Filter people, groups, assessments and text. Filters use existing results without rerunning the study.
- Open a result, read its passage, context and assessment, then inspect the **source**.
- Read **Method and coverage** before drawing conclusions about the whole collection. A partial collection does not establish what the missing material says.
- **Ask about these results** sends the currently filtered set with a follow-up question. The previous study is kept.

If the conversation has no study yet, the lesson shows the document and explains how to request one. Steps requiring results are skipped; return to them once the analysis is available.
