---
title: Advisor skills
description: How to request tasks, understand tool selection and check the sources used.
---

**Skills** are the Advisor's ways of carrying out tasks. You do not need to know tool names or select them from a list. Describe your goal, sources and expected result; the Advisor chooses available capabilities for the question and your access.

## What you can ask

| Area | Example question |
| --- | --- |
| Legislation | “Compare the current stages of these two draft laws and identify the next steps.” |
| Votes | “How did each club vote on this amendment? Show the results in a table.” |
| Recordings and transcripts | “Find this person's statements about energy in this sitting. Include quotations and recording timestamps.” |
| People and organizations | “Summarize this person's documented activity during the specified period and cite the sources.” |
| Media | “Compare these politicians' arguments about this topic in posts from the last month.” |
| Repository | “Find passages about this obligation in the documents we can access.” |
| Alerts and Smart Folders | “Summarize this alert's latest matches and identify those concerning the specified project.” |
| Earlier conversations | “Find the earlier conversation about this project and recall its findings.” |

A question can combine several areas. Naming the document, person, sitting or period helps distinguish relevant material from similar results. **@** and **+ → Repository** let you attach an exact source.

## Research and visualizations

To examine a collection, define its scope and a common assessment criterion. For example:

> Analyze a named club's statements from a specified Sejm sitting about Ukraine. Distinguish positive, negative, neutral and ambiguous tone. Include quotations and a comparison of speakers.

The Advisor can present the results in an **Analysis document**, with text, a table, chart or research map. You do not need to activate a separate Research or Visualization mode. **Plan** lets you review the approach first and later requires **Execute plan**.

Study filters and views use existing results. A follow-up question starts new work. Learn to read these results in the [Plans and research lesson](/en/advisor/tutorials).

## Check how the answer was produced

Expand **Worked for** above an answer to see its searches and tools. A tool entry shows details of the operation. Citations in the answer lead to the material used.

Before relying on a finding, inspect the original passage and its context. An empty search does not prove that an event did not happen, and an unavailable assessment is not a negative result. For collection-wide research, also check **Method and coverage**.

If the answer misses your intent, refine the sources, period or criterion in the same conversation. Start a new conversation for an unrelated topic. Projects organize conversations but do not automatically attach every chat to each question.
