To begin working with the Persate platform, complete three steps: create an account, secure it, and sign in for the first time. The entire procedure takes approximately five minutes and requires access to a mobile device to configure security.

## Prerequisites

* An active email address (used for verification and communication).
* A mobile device with an installed authenticator application supporting the TOTP standard (e.g., Google Authenticator, Authy, Microsoft Authenticator).

Access to the platform does not require an invitation code or payment information during registration.

## Implementation stages

1. **[Account creation](/getting-started/create-account)** — choose an authentication method (email or SSO).
2. **[Two-factor authentication](/getting-started/set-up-two-factor)** — pair an authenticator application to secure the profile.
3. **[First sign-in](/getting-started/first-login)** — introduction to the main dashboard (Cockpit).

## Empty view and error states

* *"Verification link expired"* — the link sent in the email is no longer valid. Repeat the registration process or use the password reset option.
* *"Account already exists"* — attempt to register with an email address already in the database. In this case, use the sign-in screen.
