Three steps are required before working with Persate:

1. **[Create an account](/getting-started/create-account)** — registration is available via email and password, or through single sign-on with Google or Microsoft.
2. **[Configure two-factor authentication](/getting-started/set-up-two-factor)** — pairing an authenticator application is mandatory for every user.
3. **[Sign in for the first time](/getting-started/first-login)** — followed by an orientation to the Cockpit.

The full process takes approximately five minutes. Only the two-factor step requires a mobile device.

## Prerequisites

- An accessible email address. A verification link is dispatched during registration.
- An authenticator application installed on a mobile device. Google Authenticator, Authy, 1Password, Microsoft Authenticator, or any other TOTP-compliant application is suitable.

No invitation code or payment information is required.
