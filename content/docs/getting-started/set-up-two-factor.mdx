---
title: Two-factor authentication configuration
description: Securing the account using an authenticator application and the TOTP standard.
---

Two-factor authentication (2FA) is a mandatory security requirement for every profile on the Persate platform. Every sign-in attempt, in addition to the password, requires entering a temporary code from a mobile application.

The *Set Up Authenticator* screen is displayed automatically during the first sign-in after account creation.

## Device pairing procedure

1. Open the authenticator application on a mobile device and select the option to add a new account (the **+** icon).
2. Scan the QR code displayed in the browser using the camera. If scanning is not possible, manually enter the configuration key visible below the code.
3. Enter the six-digit code generated by the application into the appropriate field in the Persate interface.
4. Select **Verify and finish setup**.

**Important:** Without access to the authenticator application, it is impossible to sign in independently. Contacting technical support will be necessary. Using applications that offer cloud backup (e.g., Authy or 1Password) is recommended.

## Empty view and error states

* *„Invalid code”* — the entered code is incorrect or expired. The code changes every 30 seconds; ensure the current value is entered.
* *„Clock desync”* — an error resulting from a time difference between the server and the mobile device. Ensure automatic time synchronization is enabled in the mobile device settings.
