## Authentication procedure

To sign in, navigate to [persate.com](https://persate.com) and select **Sign in**. Authentication proceeds in two stages:

1. **Email address.** Enter the address associated with the account and select **Continue**. The password field is then revealed.
2. **Password.** Enter the account password and select **Sign In**.

A subsequent prompt requests a **six-digit verification code** from the paired authenticator application (see [Configuring two-factor authentication](/getting-started/set-up-two-factor)). Once accepted, the application redirects to the Cockpit.

For accounts created via single sign-on, the **Continue using Google Account** or **Continue using Microsoft Account** button replaces the email and password stages.

### Forgotten password

The **Password reset** page (URL: `/password-reset`) accepts an email address and dispatches a reset link to that address. Selecting the link in the resulting email leads to a page where a new password may be set. Once signed in, the password may also be changed under **Settings**.

## Initial orientation

The post-authentication landing screen is the **Cockpit** (URL: `/dashboard`). For most users, this is the principal working surface.

The following elements warrant attention from the outset:

- **The sidebar (left).** Provides navigation to every functional area of the application. Items annotated with **SOON** are reserved for forthcoming functionality.
- **Sidebar header controls.**
  - **Upload** opens a side panel for adding files to the Repository.
  - **Search** opens a global search dialogue covering files across the application.
