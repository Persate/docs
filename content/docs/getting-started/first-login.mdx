title: First sign-in
description: The authentication procedure and interface orientation after accessing the Cockpit.
---

Sign-in takes place on the [persate.com](https://persate.com) homepage after selecting **Sign in**.

## Sign-in process

Authentication requires completing two steps:

1. Enter the email address and select **Continue**.
2. Enter the password and select **Sign In**.

After providing valid credentials, the platform requires entering a six-digit code from the authenticator application. When signing in using a Google or Microsoft account, simply select **Continue using Google Account** (or Microsoft).

## Password reset

In the event of a lost password, use the form at `persate.com/password-reset`. The platform dispatches a link to the provided address to set a new password. Changing the password is also possible after signing in, under the **Settings** section.

## Startup navigation

After successfully signing in, the default view is the **Cockpit**. Key interface elements include:

* **Sidebar** — the main navigation menu on the left side.
* **Upload** — the button opening the document addition panel.
* **Search** — the magnifying glass icon launching the global search.

## Empty view and error states

* *„Invalid credentials”* — incorrect email address or password.
* *„Code mismatch”* — the entered TOTP code is incorrect.
* *„Account locked”* — too many failed sign-in attempts. Wait a few minutes or reset the password.
