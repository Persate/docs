Organization management is in **Settings → Organization**. Administrators manage the organization. Members can read its profile, external-provider permissions and experiments; member management, groups and usage require an administrator.

## Organization pages

* **General** — organization name and report privacy. **Detailed source context in reports** controls whether report generation receives source headlines, links and event details. When off, reports use topic summaries and counts.
* **Members** — search members, invite users, manage pending invitations, change roles and open per-user usage details.
* **Groups & permissions** — search groups, manage members and assign access to Repository files.
* **Usage & plan** — current plan and billing cycle, storage and AI token totals, accessible files, member count and resource allowances. Per-member usage loads when opened.
* **External providers** — providers that receive organization data, the processing purpose, data shared, dependent functions and the consequence of disabling each permission.
* **Experimental features** — separate opt-in controls for optional Advisor and global-search assessments and generated alert banners. Each experiment also requires its provider permission and service availability.

Administrative visibility does not replace organization feature access or record-level permissions. The accessible-file count follows the current administrator's file access. Unlimited allowances are shown as unlimited; missing usage data shows a retry state.

## Roles

* **Admin** — manages the organization and its settings.
* **Member** — uses the enabled features and resources shared with the member.

Changing a role takes effect through authenticated workspace permissions. Refresh or sign in again if a surface still shows the old role.

## Provider permissions and consequences

Permissions apply to the processing purpose shown in each row. Multiple rows can name the same provider because different functions have independent controls.

Disabling external alert judging stops new AI alert matching and delivery; there is no local judging model. AI judging in smart folders also stops, while structural filters and manually selected content may remain available. Disabling the Advisor provider prevents new Advisor work. Disabling report generation prevents new reports. Existing conversations, reports and stored content are retained.

Disabling cloud image assessment stops licensed-image selection because there is no local assessor. Generated banners have a separate provider permission and experiment. Other permissions describe their own fallback or unavailable function in the table; disabling one purpose does not disable every external service.

Changes apply within 60 seconds. New Advisor and optional assessment requests check the latest permission. Requests already processing may finish.

## Saving and loading errors

Organization changes require **Save changes**. Disabling a provider or allowing detailed report context opens a confirmation explaining its effect. Unsaved changes remain visible if a save fails. If another administrator changed the same setting, reload the latest values before retrying.

If a workspace allowance is exhausted, eligible AI background work can be skipped and interactive AI actions can be rejected until the allowance resets or the plan changes. Existing content remains available according to its access rules. Usage is an operational summary, not an invoice.
