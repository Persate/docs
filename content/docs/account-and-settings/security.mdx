title: Security and privacy
description: Account protection management — password change, two-factor authentication, and active session monitoring.
---

The **Security & Privacy** panel is used to protect profile access and monitor login history and active devices.

## Login password

The **Change password** option opens the access key change form. The new password must consist of at least eight characters, including at least one digit and one special character. For SSO accounts (Google/Microsoft), password changes occur on the external provider's side.

## Two-factor verification (2FA)

Two-factor authentication is required for every account.

* **Status** — the *Live* badge confirms active protection.
* **Changing the authenticator application** — the **Replace authenticator** button allows deregistering the current application and generating a new QR code. This process must be completed immediately after initiation.

## Access monitoring

* **Active sessions** — a list of devices currently signed into the profile. The row labeled as *This device* represents the current browser. The **Sign out all other devices** button allows remotely terminating all other sessions.
* **Login history** — a chronological log of the last 15 events (logins, logouts, account parameter changes) along with the IP address and device type.

## Data export (GDPR)

The feature labeled as **coming-soon** will eventually allow downloading a full archive of account data (profile, conversations, alerts). Until its launch, direct requests to technical support.

## Empty view and error states

* *„Session management unavailable”* — for a given authentication type, the remote session logout feature is not supported.
* *„Login history not exposed”* — lack of access to the audit event log for the current profile.
