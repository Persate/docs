title: Account
description: Identity management — profile picture, display name, email address, and assigned roles and groups.
---

The **Account** panel is used to manage identity elements visible to other collaborators within the workspace. It is the default panel opened upon accessing the settings.

## Identity

* **Profile picture** — acceptable formats are JPG, PNG, or WebP up to 2 MB in size. Selecting the avatar opens a file selection window. Removing a custom photo using the **Remove custom photo** button restores the automatically generated avatar or the one provided by the SSO provider.
* **Display name** — the label presented in comments and reports. If no custom name is provided, the system uses data supplied by the identity provider or the email address. Confirm changes using the **Save** button.
* **Email** — the primary address for signing in and notifications. Changing the address requires selecting the **Change email** option and confirming with links sent to both the old and new addresses (not applicable to SSO accounts).

## Permissions and groups

Information regarding the access level is presented in the lower part of the panel:

* **Role** — the permission level in the workspace (e.g., **Administrator**, **Member**). This is a read-only field.
* **Groups** — a list of groups to which the profile is assigned. Group membership determines access to shared documents and alerts.

Changes to roles and group affiliations are performed by an administrator from the **Admin Panel**.

## Empty view and error states

* *„You're not currently a member of any groups”* — the profile has not yet been assigned to any collaborator group.
* *„Change email unavailable”* — the feature is unavailable for accounts integrated via Google or Microsoft; the address change must occur on the provider's side.
