Settings have their own pages. To open them, select the avatar in the top-right corner and choose **Account settings** or **Preferences**; on a phone, select **Profile** in the dock at the bottom of the screen.

While Settings is open, the sidebar shows the settings navigation instead of the main navigation. **Back to app** at the top of it returns to the page that was open before Settings. On narrow screens, the bar at the top of the screen shows **Back to app**, the name of the current page and **Sections**, which opens the settings navigation.

## Settings pages

The settings navigation is divided into three groups.

| Group | Page | Contents |
| :--- | :--- | :--- |
| **PERSONAL** | **Account** | Profile photo, display name, email, role and groups. |
| | **Security & Privacy** | Password, two-step verification, sessions and trusted devices, login history, analytics cookies and personal data export. |
| | **Notifications** | Email, in-app and phone notifications. |
| | **Preferences** | Language, theme, Advisor output style and other personal preferences. |
| **PLATFORM** | **Sources** | The catalogue of sources monitored by Persate, open to every member. See **[Sources](/sources)**. |
| | **MCP & AI apps** | The MCP server address, setup guides for ChatGPT and Claude, the access the organization allows and the AI apps connected to the account. See **[MCP and AI apps](/account-and-settings/mcp)**. |
| **ORGANIZATION** | **General** | The organization name and settings that apply to the whole organization. |
| | **Members** | Organization members and invitations. |
| | **Groups & permissions** | Groups and the Repository files shared with them. |
| | **Usage & plan** | The organization's plan and usage. |
| | **External providers** | Permissions for external services that process the organization's data. |
| | **Experimental features** | Optional experimental functions. |
| | **MCP access** | Whether AI apps can connect to the organization's data, with which toolsets and access mode, and the AI apps connected by members. |

**Members**, **Groups & permissions**, **Usage & plan** and **MCP access** are shown only to organization administrators. Other members can open **General**, **External providers** and **Experimental features** to read the organization's settings; these pages state that **Only organization administrators can change these settings.**

Personal settings apply only to the signed-in user. Role, group membership, the organization's functions and its processing permissions are managed by an organization administrator — see **[Administration](/administration)** and **[Users and groups](/administration/users-and-groups)**.

## Saving and errors

* Switches on personal pages save as soon as they change. If saving fails, Persate restores the previous value and shows an error; check the connection and try again.
* The display name is saved with **Save**; a new email address is entered in its own dialog.
* Organization pages collect changes until **Save changes** is selected. While changes are pending, the page shows **Unsaved changes** and **Discard changes**. Changes with wider consequences, such as disabling a provider or granting consent to one, first open **Review organization changes**, confirmed with **Confirm and save**.
* If saving organization changes fails, the edits stay on screen with an error. **Reload latest settings and discard edits** loads the current values, for example when another administrator has changed the same setting.
* **MCP access** is saved with **Save changes**; **Discard draft and reload** discards the edits and loads the current policy.
