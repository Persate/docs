Open the profile menu in the top navigation and select **Settings**. Settings opens as a separate area. Select **Back to app** to return to the platform.

## Settings sections

* **Account** — profile photo, display name, email, workspace role, and group memberships.
* **Security & Privacy** — password, two-step verification, sessions, trusted browsers, and login history.
* **Notifications** — email, alert-match, daily-report, and Advisor notification preferences.
* **Preferences** — interface language, theme, Advisor output style, feature banners, procedural votes, and Editor import defaults when available.
* **Analysis** — future synchronization and suggestion controls. These rows are currently marked **Coming soon**.

Settings are personal unless the row explicitly describes a workspace-managed value. Role, group membership, feature access, and organization policy are controlled by an administrator.

**Organization** contains the organization profile, members, groups, usage, external-provider permissions and experiments. See **[Administration](/administration)** for administrator controls and their effects.

## Save and error behavior

Most personal toggles save immediately. Organization changes require **Save changes**; a failed save keeps the draft visible. Display-name and form changes require their visible confirmation button. If a save fails, Persate restores the previous value and shows an error; retry once after checking the connection.
