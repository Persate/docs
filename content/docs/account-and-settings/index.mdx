The **Settings window** is the central point for managing the profile and operating parameters on the platform. It is designed as an overlay accessible from anywhere in the application, which allows changing settings without losing the current work state.

Access the settings by selecting the profile icon in the top navigation bar, followed by the **Settings** button with the gear icon.

## Settings structure

Settings are divided into two categories:

### GENERAL category

* **Account** — platform identity: profile picture, display name, email address, and roles.
* **Security & Privacy** — access protection: password change, two-factor authentication, and a list of active and past sessions.
* **Notifications** — configuration of system notifications and email alerts.
* **Preferences** — interface personalization: color themes, language, and time zone.

### PLATFORM category

* **Advisor** — AI Advisor operating parameters (e.g., analysis depth).
* **Analysis** — document synchronization and smart suggestion settings.

## Empty view and error states

* *„Settings unavailable”* — error loading account parameters. Refreshing the page is recommended.
* *„Feature locked”* — certain settings (e.g., changing the email for SSO accounts) are managed by external providers and remain locked in the Persate interface.
