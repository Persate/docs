title: Preferences and notifications
description: Interface personalization, email notification settings, and data analysis parameters.
---

The **Preferences**, **Notifications**, and **Analysis** panels are used to configure the platform's operation and appearance. Certain features marked as **coming-soon** will be made available in upcoming releases.

## Appearance and interface

The visual layer can be managed in the **Preferences** panel:

* **Theme** — select between *Moonlit night* (dark), *Sunny mode* (light), and *Follow system* (automatic).
* **Feature banners** — the **Reset** button restores all previously hidden introductory banners on module pages.

## Email notifications

The **Notifications** panel allows managing outbound communication:

* **Product updates** — the only currently active toggle, controlling the delivery of information about new features.
* **Security alerts** — (in preparation) notifications about logins and password changes.
* **Weekly digest** — (in preparation) a summary of changes in monitored resources.

## Analysis parameters

The **Analysis** panel (features available soon) contains:

* **Sync interval** — the frequency of downloading files from external sources (Google Drive, OneDrive).
* **Smart suggestions** — a toggle for automatically recommending related proceedings and documents.

## Empty view and error states

* *„No banners hidden”* — no banners to reset; the button remains inactive.
* *„Feature coming soon”* — an attempt to configure a feature planned for the future.
