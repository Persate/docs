## Notifications

Open **Settings → Notifications**. The following preferences are active and save immediately:

* **Product updates** — occasional product and release email.
* **Alert emails** — email when an enabled alert confirms a match.
* **Alert match notifications** — in-app and phone notification for a confirmed alert match.
* **Daily report notifications** — in-app and phone notification when the morning report is ready; disabled until you opt in.
* **Advisor notifications** — in-app and phone notification when an Advisor task finishes.

Alert matches themselves appear under **CORE → Tracker**. The navbar inbox is reserved for product announcements and direct messages.

**Security alerts** and **Weekly digest** are marked **Coming soon**; their disabled switches do not change delivery.

## Preferences

Open **Settings → Preferences** to configure:

* **Appearance** — Sunny mode (the default), Moonlit night, or Follow system. An existing saved theme stays in effect; changing the appearance applies immediately and saves the choice for future sessions.
* **Language** — English or Polski. The interface changes immediately and the choice saves to the account for future sessions. Dates and numbers follow the selected language; source documents and authored content keep their original language.
* **Feature banners** — restore dismissed introductory banners.
* **Procedural votes in Ledger** — show votes that are hidden by default, such as agenda changes, recesses, and quorum checks.
* **Editor document uploads** — when Editor is enabled, choose whether Persate asks every time, saves imports to Repository, or uses them only for that document. The Repository option appears only when Repository is also enabled.

Change the language in **Settings → Preferences**. This browser remembers the choice and uses it on future sign-in screens. Without a saved choice, Persate uses Polish for connections from Poland and English for connections from other countries. The country is estimated from the connection's IP address; a VPN can change the result. If the country cannot be determined, Persate uses a supported browser language and otherwise English. The account preference applies after sign-in. Changing language keeps the current page and unsaved form content.

**Timezone** is marked **Coming soon**. Its displayed value is informational and cannot currently be changed.

### Advisor

When Advisor is enabled, its preferences are grouped under **Advisor**. This section is also available from **+ → Preferences** in a conversation, without leaving the draft.

* **Advisor output style** — Verbose, Compact, or Hidden while the Advisor works. Completed activity remains collapsed.
Under **+ → Preferences → Advisor**, **Open Advisor sources** defaults to **Advisor right pane**. In the desktop app, the other choice is **Open in platform**: it navigates to the selected Persate page in the same app window. External websites stay in the Advisor pane under either choice. In the web version, **New browser tab** opens the source in a separate browser tab. The setting applies to source chips, document links, research sources and attached references. A recording link keeps its selected moment, and a file link keeps its document target.

These choices apply immediately, including when Preferences is open in the adjacent workspace, and save to the account for future sessions.

## Analysis

Both **Synchronization interval** and **Smart suggestions** under **Settings → Analysis** are marked **Coming soon**. Changing the visible disabled or placeholder controls does not activate cloud synchronization or proactive suggestions.

## Troubleshooting

* Save error — Persate restores the previous value; check the connection and retry.
* Language save error — the interface keeps the selected language in this browser, but the account preference has not been saved. Check the connection and select the language again.
* No Editor preference — Editor is not enabled for the organization.
* No Repository choice under Editor storage — Repository is not enabled.
* **No banners hidden** — there is nothing to reset.
