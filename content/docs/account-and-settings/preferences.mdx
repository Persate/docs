title: Preferences and notifications
description: Interface personalization, email notification settings, and data analysis parameters.
---

The **Preferences**, **Notifications**, and **Analysis** panels are used to configure the platform's operation and appearance. Certain features marked as **coming-soon** will be made available in upcoming releases.

## Appearance and interface

The **Preferences** panel is used to manage the visual layer and selected operating parameters:

* **Theme (Appearance)** — select between *Moonlit night* (dark), *Sunny mode* (light), and *Follow system* (automatic).
* **Feature banners** — the **Reset** button restores all previously hidden introductory banners on module pages.
* **Procedural votes in Ledger** — a toggle that controls whether procedural votes (agenda changes, breaks, quorum checks) are displayed in the Voting ledger. They are hidden by default to reduce noise; enabling the toggle reveals them.
* **Language** — a row in preparation; the platform currently operates in English only (*English*).
* **Timezone** — a row in preparation; *(GMT +2:00) Warsaw* currently applies.

## Email notifications

The **Notifications** panel is used to manage outbound communication. Two toggles are currently active:

* **Product updates** — information about new features and releases.
* **Alert emails** — an email sent when one of the enabled alerts is triggered.

The remaining items are marked as in preparation:

* **Security alerts** — notifications about logins, password changes, and two-factor authentication events.
* **Weekly digest** — a Monday summary of changes in monitored documents.
* **In-app & push** — real-time alerts inside the platform and on a mobile device.

## Analysis parameters

The **Analysis** panel (features available soon) contains:

* **Sync interval** — the frequency of downloading files from external sources (Google Drive, OneDrive).
* **Smart suggestions** — a toggle for automatically recommending related proceedings and documents.

## Empty view and error states

* *"No banners hidden"* — no banners to reset; the button remains inactive.
* *"Feature coming soon"* — an attempt to configure a feature planned for the future.
