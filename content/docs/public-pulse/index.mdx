**Media** follows the public posts on X published by the stakeholders tracked in Persate. Posts are grouped into events and stories, clustered into topics and listed in a chronological feed. Open the module from **PUBLIC → Media** in the sidebar. It is available when it is enabled for the organization.

## Tabs

* **Events** — the default view. Shows current events grouped into stories, on a timeline or on a board of categories. See [Events and stories](/public-pulse/events).
* **Feed** — the latest posts as cards, newest first.
* **Topics** — a table of topics with activity metrics; each row opens a topic page.

The selected tab is part of the page address, so a link to a tab can be shared.

## Filters

The filters sit in the right-hand panel (on a phone, the **Filters** button). They stay set for the rest of the session in the same browser tab.

| Filter | Tab | What it does |
|---|---|---|
| **Search** | Feed, Topics | Text search in posts. |
| **Timeline range** | Events | **6 h**, **24 h** (default), **7 d**, **30 d** or **90 d**. |
| **Custom period** | Events | A date range instead of a preset; **Timeline range** then shows **Custom period**. Choosing a preset clears the date range. |
| **Date Range** | Feed, Topics | The same date range as **Custom period**, under its Feed and Topics name. |
| **Categories** | Events | Limits the view to selected categories; empty means **All categories**. |
| **Sort events** | Events | **Newest activity** (default), **Most views**, **Most likes**, **Most reposts** or **Highest engagement**. |
| **Sort by**, **Order** | Topics | **Likes + Views** (default), **Active people**, **Tweets**, **Momentum** or **Topic name**; **Descending** or **Ascending**. |

**Clear all filters** appears when the search, dates, categories or event sorting differ from the defaults, and restores them.

At the bottom of the panel, *Last synced …* shows when posts were last collected. The dot next to it indicates whether the view is up to date or new content is available.

## Feed

The **Feed** tab lists posts from the newest. Further posts load while scrolling; *That's everything so far.* marks the end.

Each card shows the author's photo, name, party group, handle and the time of posting, followed by the text, attached media and, for quotes and reposts, the referenced post. A label above the author marks the kind of post: **Repost**, **Reply** (*Replying to @…*) or **Quote** (*Quoting @…*); original posts carry no label. Counters below the content show replies, reposts and quotes, likes and views. **Open on X →** opens the post on X.

Persate keeps posts that were later deleted:

* **Archived** — the post was removed from X. The card shows when it was deleted and how long after posting.
* **Checking X status** — X did not return the post in the latest check, and the deletion is being confirmed.

## Topics

The **Topics** tab lists topics with **Topic**, **Tweets**, **Active people**, **Likes + Views**, **Momentum** (the change in activity, as a percentage) and **Top tag / club**. Sort the table with **Sort by** and **Order** in the panel. Selecting a row opens the topic page for the current date range.

The topic page shows the topic name and description, then four sections:

* **Activity** — post volume across the selected period, with its peak.
* **Active stories** — stories from the **Events** tab linked to the topic in the selected period, with the number of active events, matching posts and the time of last activity. **Open story** opens the story page.
* **Active people** — the people posting on the topic, with **Club**, **Posts** and **Engagement**, ordered by engagement.
* **Posts** — the topic's posts; **Load more** shows further posts.

The right-hand panel (on a phone, the **Details** button) shows **At a glance** — **Window**, **Posts**, **Active people**, **Momentum**, **Top hashtag** and **Leading club** — and **Reactions**: **Replies**, **Reposts**, **Likes**, **Quotes** and **Views**.

When a topic has faded, its page shows *This topic is no longer active.* with **Browse current topics** and **Open event timeline**. If the topic now continues as a story, the story page opens instead.

## Empty and error states

* *No tweets match your filters* — the filters exclude every post in **Feed**; widen the date range or clear the search.
* *No tweets yet* — no posts from tracked stakeholders have been collected yet.
* *Couldn't load Media* — the feed failed to load; **Retry** loads it again. If the account lacks permission for the feed, the message says so.
* *No topics match the current filters. Try broadening the date range.* — the **Topics** table is empty for the current filters.
* *No events in this range* — the **Events** tab has nothing to show; choose a wider period or another category.
