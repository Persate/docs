title: Public Pulse
description: Activity of monitored stakeholders on X presented as a topic map, a list of posts, or a topic overview.
---

**Public Pulse** gathers stakeholder activity on X. Every post, reply, or repost enters a shared stream that can be filtered and analyzed in several modes.

Access to the view is provided by the **KNOWLEDGE BASE → Public Pulse** entry in the sidebar.

## Presentation modes

Three modes can be switched between at the top of the screen:

* **Map** — a topic map filling the entire workspace, presenting grouped activity.
* **Feed** — a chronological list of post cards, optimal for a quick overview of the latest activity.
* **Topics** — a table of topics with metrics and sorting.

## Topic map

The **Map** mode presents posts as point clouds. Related posts are grouped into topics (clusters). Each point corresponds to a single post, and its placement reflects thematic proximity. Hovering over a point opens a post preview with the stakeholder's avatar and name, the nature of the post (e.g., *"Replying to…"*, *"Quoting…"*, *"Repost by…"*), the content, and counters for likes, reposts, and replies. Selecting a cloud navigates to the detail of a given topic.

In the top-left corner of the map, a **Topic map** header is visible along with information about the time of the last recalculation (*"Updated…"*).

### Timeline

A timeline is located at the bottom of the page. Dragging the slider — or starting playback with the **Play** button — moves the time window across the last dozen or so days, and the map recalculates the activity from the selected range in real time: clouds grow, shrink, and shift as topics rise and fade. The window width can be set to **1d**, **3d**, or **7d**. The timeline responds only to user actions and does not override the date range selected in the sidebar until it is moved.

## Topics view

The **Topics** mode is a tabulated list of topics. Selecting a row opens the **topic detail** — a separate view composed of:

* **Header with statistics** — the topic name, date range, total number of posts, number of active people, a dynamics indicator (**Momentum**), and — when available — the dominant hashtag and dominant club.
* **Reactions** — an engagement overview in tiles: replies, reposts, likes, quotes, and views, each with a total value and an average per post.
* **Activity over time** — a bar chart showing the intensity of activity over time within the topic.
* **Active people** — a table of the most active people in the topic with their club, number of posts, and contribution to engagement; the table can be sorted.
* **List of posts** — the posts making up the given topic.

When a topic has faded, the detail displays the message *"This topic is no longer active"* with the option to return to the topic list.

## Related in Persate

Topic details are cross-referenced with the rest of the platform in the **Related in Persate** section, grouping matches into categories: **Legislation**, **Stakeholders**, **Alerts**, and **Smart folders**. Each entry is a link leading to the corresponding place in the platform.

## Post card

Every post is labeled with a tag indicating its nature: **Original** (own post), **Reply** (response), **Retweet** (repost), or **Quote** (repost with commentary). Posts deleted from X but previously captured are labeled as *Archived*.

## Sorting topics

In the **Topics** mode, the sidebar provides a **Sort by** section, allowing the topic list to be ordered by: **Likes + Views**, **Active people**, **Tweets**, **Momentum**, or **Topic name**. Selecting the active criterion again reverses the sort direction.

## Filtering

The sidebar provides tools for narrowing the stream:

* **Search** — text search within post content.
* **Date Range** — restricting results to a selected time period.
* **Clear all filters** — clearing all active filters.

## Synchronization status

The indicator in the sidebar footer provides information about the displayed data state:

* **Blue dot** — data is up to date.
* **Amber dot** — new posts are available and being processed.

*"Last synced…"* shows the time of the last successful update.

## Empty view and error states

* *"No tweets match your filters"* — active filters exclude all posts.
* *"No tweets yet"* — no new posts in the monitored stream.
* *"Couldn't load Public Pulse"* — server connection error. Refreshing the page is recommended.
