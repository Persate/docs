The **Voting ledger** is a chronological record of all Sejm votes. Every entry contains the official numerical result, resolution information, and a detailed per-mandate vote distribution.

Access to the module is provided by the **KNOWLEDGE BASE → Ledger** entry in the sidebar.

## List structure

Votes are grouped by **proceeding** and presented in descending order. The view is controlled by a page size selector, and access to historical data is obtained through pagination.

## Voting card

Every vote is represented by a card containing:

* **Identifier** — the proceeding number (**Proceeding**) and vote number (**Vote**).
* **Result** — resolution information: **Passed**, **Rejected**, **Quorum present**, or **Quorum missing**.
* **Vote distribution visualization** — a segmented color bar: **Yes** (blue), **No** (red), **Abstain** (amber), **Present** (light grey), and **Absent** (grey).
* **Metrics** — the total number of votes cast (**Votes cast**) or present members (**Members present**).

Selecting a card opens the detailed view with the mandate chamber map.

## Search and filtering

The **Search** field in the sidebar allows filtering records currently loaded on the page by title, topic, or vote number. Matching is case-insensitive and updates in real time.

## Resolution rules

The platform records the majority type applied for each vote:

* **Simple** — more votes in favor than against.
* **Absolute** — more than half of the statutory number of stakeholders.
* **Qualified** — a constitutionally defined threshold (e.g., 2/3 or 3/5).

The majority type directly determines the assignment of the **Passed** or **Rejected** label.

## Empty view and error states

* *„No votings match your search"* — no records on the current page match the query.
* *„No votings available"* — the system has not recorded any votes in the selected range. Reloading the page is recommended.
