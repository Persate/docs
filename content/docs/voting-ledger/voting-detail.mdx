The **Detailed view** provides a complete record of a single vote. The screen consists of the overview section, source documents, and an interactive chamber map.

Access to the view is obtained by selecting any card in the **Voting ledger**.

## Overview and metrics

The main panel contains key resolution parameters:

* **Resolution status** — the label **Passed**, **Rejected**, **Quorum present**, or **Quorum missing**, along with information about whether the required threshold was reached.
* **Voted at** — the exact time the votes were cast.
* **Members present** — the number of stakeholders recorded in the chamber.
* **Majority** — the applied majority rule (**Simple**, **Absolute**, or **Qualified**).
* **Turnout** — attendance expressed as a percentage and in absolute terms.

## Linked documents

This section lists source materials linked to the vote (parliamentary prints, ELI acts, committee reports). The document of greatest substantive significance is highlighted with a **Priority** badge. Every entry contains an action button that opens the document in a new tab.

When no materials are available, the message *"No linked documents were found for this vote yet"* is displayed.

## Interactive chamber map

The map reproduces the actual seating layout of the Sejm. Every mandate is marked with a dot in the color of the cast vote:

* **Blue** — **Yes** (in favor).
* **Red** — **No** (against).
* **Amber** — **Abstain**.
* **Light grey** — **Present** (for attendance-checking votes).
* **Grey** — **Absent**.

### Club filtering

Above the map, a list of parliamentary clubs is displayed. Selecting a specific group restricts the map visibility exclusively to its members. The club indicator color represents its majority vote. The **All seats** option restores the full chamber view.

### Mandate details

Hovering over a point on the map displays the stakeholder's identity and their cast vote. The seating layout corresponds to the official daily map from the Chancellery of the Sejm.

## Empty view and error states

* *"No linked documents were found for this vote yet"* — no source materials are assigned for the given resolution.
* *"Couldn't load voting details"* — server connection error or insufficient permissions to view details. Reloading the page is recommended.
* *"No options available"* — for standard votes, the option selection section remains hidden.
