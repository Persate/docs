The source catalogue is a read-only overview of the data sources Persate works with: what each source contains, whether it is currently available, how much of it is covered, and which parts of the platform use it. Open **Settings**, then select **Sources** under **PLATFORM**. The catalogue is available to every member of the organization. It does not connect cloud drives and does not change how sources are configured.

## Reading the table

Each row describes one source:

* **Source** — the source name and a short description of its content.
* **Status** — **Available** when the source works normally, or its current reported state.
* **Availability** — icons for the parts of Persate that use the source, such as **Repository**, **Stakeholders**, **Legislation**, **Ledger**, **Recordings**, **Search**, **Advisor**, **Alerts**, or **Media**. An icon links to that part of the platform when it has its own page.
* **Coverage** — the scope of the current data, such as the number of documents, votes, or posts. For searchable sources, a bar shows the share of records ready for full search.
* **Importance** and **Labels** — whether automated importance assessment and labeling are processing the source's items. Hover over the icon to see when an item was last analyzed, how long no item has been analyzed, or that the analysis does not apply to the source.
* **Refresh** — how often the source is updated.
* **Alerts** — whether and how the source feeds alert monitoring. Hover over the value for details of the alert coverage.
* **Last update** — the latest reported update, when available.

On narrower windows, secondary columns are hidden. On a phone, the status comes first and **Importance** and **Labels** are combined in **Analysis**.

## Filtering the catalogue

The sidebar offers:

* **Search sources** — search by name or description, for example *RCL*, *recordings*, or *journal*;
* **Category** — **All sources** or a single category;
* **Alerts enabled only** — only sources that feed alerts;
* **Show raw-only sources** — on by default; switch it off to hide sources available only as raw data.

The two switches become active once live source status has loaded. Filters change only the view; they do not enable, disable, or resynchronize a source. **No sources match these filters** means the search or filters exclude every source; clear them to see the complete catalogue.

## When live status is unavailable

If live source status cannot be loaded, the catalogue stays visible with the banner **Live telemetry is unavailable. The source catalog remains available.** and a **Retry** button. In that state the rows still show the names and descriptions, but status, availability, alerts, refresh, and last update show a dash. Use such a row for orientation only; open the relevant part of the platform to confirm what is available. If the catalogue itself cannot be loaded, **Couldn't load sources** is shown with **Try again**.

## Interpreting status

Status, availability, and coverage answer different questions:

* a source can be listed but temporarily unavailable;
* a source can be used in one part of the platform but not feed alerts;
* coverage can be partial even when the status is **Available**;
* a missing last-update value means no update was reported, not that the source was never updated.

## Source passages

An Advisor citation of a recording transcript, or a **Transcript** result in search, opens the exact cited passage on a separate page. The page shows **Transcript excerpt** and the **Original source passage** as quoted text. Cited fragments of legislative documents open in the legislation reader instead, with the passage highlighted; see [Published acts and publications](/legislation-tracker/published-acts).

**Source passage unavailable** means the passage could not be opened: it may no longer be available, or the account may no longer have access to it.
