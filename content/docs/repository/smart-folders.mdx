**Smart folders** are saved queries that automatically update their contents. Every document meeting specified criteria — such as a text phrase, file type, date, or tag — appears in the folder without the need for manual transfer.

A smart folder is not a physical location; files remain in the repository, and their folder membership is determined dynamically based on configured filters.

## Example use cases

* Aggregating all documents containing the phrase *„legislation 2025"*, ordered from newest.
* Isolating PDF files longer than 50 pages that do not yet have assigned tags.
* Consolidating documentation related to a specific stakeholder based on keywords.

## Configuration and editing

Smart folders are visible in the sidebar alongside the main repository view. Selecting a folder allows modifying its criteria in the sidebar:

* **Content search** — a text query (e.g., *„carbon tax"*).
* **Filters** — restrictions regarding name, date, size, document type, or source (e.g., Persate, Google Drive).
* **Sorting** — ordering results by date, size, or alphabetically.

Confirm changes using the **Save** button, which triggers an immediate refresh of the file list.

## Presentation modes

Every folder offers two data display modes:

* **Storage view** — a standard list or tile layout, optimal for downloading documents.
* **Timeline view** — a file presentation on a timeline. Enables identifying documentation density within specific time periods.

## Recommended workflow

1. Define general query criteria (e.g., a keyword only).
2. Save the folder and verify the number of returned results.
3. Narrow results by adding technical filters (e.g., selecting only the PDF format).
4. Add metadata filters (e.g., tags or document source) to exclude irrelevant entries.
5. Set the default sorting to facilitate ongoing work with the folder.

## Empty view and error states

* *„No documents match this folder's criteria"* — no files in the repository meet the conditions defined in the folder configuration.
* *„Invalid search query"* — an error in the text query syntax. Simplify the search phrase.

## Known limitations

Currently, a single smart folder can be based on a maximum of one text query combined with any number of technical filters.
