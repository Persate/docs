**WORKSPACE → Repository** lists the files the signed-in user owns and the files shared with the groups that user belongs to. The page is available when Repository is enabled for the organization; otherwise it shows **This feature is not included in your plan**.

## What Repository is for

* Keeping working documents — PDF, DOCX, XLSX and CSV files — in one place.
* Deciding, file by file, who can open a document: only its owner, or members of selected groups.
* Finding files by name or content, previewing them, and downloading one file or a ZIP archive of several.
* Analyzing documents: processed files are summarized, indexed for search and used by Advisor, Tracker and Smart Folders.

Repository is not a folder tree. All files sit in one list, and access is set on each file. Smart Folders are saved collections that point to Repository files without moving or copying them.

## Access to files

Every file has an owner and one audience:

* **Only me** — only the owner sees the file;
* **Selected groups** — members of the chosen groups see it as well. When the organization has an organization-wide group, it appears in the list as **Everyone at** followed by the organization name.

The owner changes a file's audience in the file panel. Organization administrators share files with groups from **Settings → Groups & permissions**, as described in [Users and groups](/administration/users-and-groups). Removing a group from a file ends access through that group; the file itself stays in Repository.

## Analysis after upload

A file appears in the list as soon as its upload succeeds. Persate then analyzes it in the background: it extracts the text, writes a summary, detects the language, prepares a preview and indexes the content for search.

The **Analysis** column shows a spinning icon while this runs, a tick when the file is ready and an error icon when analysis failed. While any file is being processed, the list refreshes on its own. Content search, the summary in **Description**, previews of non-PDF files and Advisor answers based on the file all depend on completed analysis.

## Repository in other modules

* **Advisor** — searches processed files and accepts them as attachments. Typing `@` in the question field opens a search across Repository and the public corpus; see the [Advisor interface guide](/advisor/conversations). When an answer cites a Repository file, the citation opens the file here with the **Cited passage**.
* **Tracker** — alerts can include company files among their sources. A match found in a file opens that file in Repository.
* **Smart Folders** — saved collections of Repository files, also listed in the Repository sidebar; see [Smart Folders](/repository/smart-folders).
* **Editor** — an imported document can be saved to Repository as a normal file; see [Import and draft](/editor/import-and-draft).

## Common states

* **No files found** — Repository is empty, or the current search, filters or smart folder exclude every file.
* **Error loading files** — the list could not be loaded; refresh the page.
* **This feature is not included in your plan** — Repository is not enabled for the organization, and the **Upload** button is hidden as well.
