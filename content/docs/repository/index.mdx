The **Repository** is a private document library associated with the account. It enables storing, searching, sorting, filtering, and previewing existing files.

Access to the module is provided by the **KNOWLEDGE BASE → Repository** entry in the sidebar.

## Feature overview

The Repository enables document management across three key areas:

* **Consolidation** — storing documents from various external sources and local drives in a single location.
* **Search** — advanced document content searching, eliminating the need to remember exact file names.
* **AI Advisor source** — documents in the repository serve as the knowledge base for the advisor when generating responses and analyses.

## Navigation and views

The platform offers two file presentation modes, switchable in the top right area of the screen:

* **List view** — a tabular layout containing the file type, name, date, and metadata. Facilitates operations on multiple files simultaneously.
* **Tile view** — a card-based presentation optimized for quick visual browsing.

The sidebar on the right side of the screen contains a **Search field** that searches document content. **Filters** are also available, allowing results to be narrowed by name, date, size, and processing status.

## Empty view and error states

* *„No documents found"* — the repository does not contain any files yet, or none match the active filters.
* *„Couldn't load documents"* — database connection error. Refreshing the page is recommended.
