The **Repository** is the document library associated with the account. It accepts PDF documents and indexes them for retrieval through full-text and semantic search.

It is accessed via the sidebar entry **KNOWLEDGE BASE → Repository**.

## Purpose

The Repository serves three principal functions:

1. **Consolidation.** A single location for documents that would otherwise reside across email, cloud-storage services, and local filesystems.
2. **Retrieval.** Full-text and semantic search across the document body, removing the need to recall exact filenames.
3. **Reference for the AI advisor.** Documents in the Repository are available as source material when consulting the in-app advisor.

## Navigation

Two view modes are available, toggled via controls in the upper-right area of the screen:

- **List view** — a tabular layout with columns for file type, name, date, and related metadata. Best suited to locating a specific file or to operating on many files in sequence.
- **Tile view** — a card grid optimised for visual browsing.

A **search field** at the top of the screen performs full-text search across document content, not only filenames. **Filters** are available for narrowing results by filename, modification date, file size, and processing status, alongside separate selectors for file type and source.
