---
title: Uploading files
description: Adding documents to the Repository and specifying the access scope.
---

**Uploading files** enables adding documents to the repository. Selecting the **Upload** option in the top left area of the screen opens the upload panel on the right side.

## File selection methods

Documents can be added in two ways:

* **Drag and drop** — files can be dragged directly from the operating system onto the upload panel area.
* **Disk selection** — selecting the drop zone opens the system file selection window.

Multiple files can be added simultaneously in a single operation. Every selected element appears on the list with a type icon, name, and an option to remove it from the batch before uploading.

**Important:** Currently, the platform supports only **PDF** files. The maximum size of a single document is **20 MB**.

## Access scope

Before uploading files, specify their visibility using the toggle:

* **Private** — files visible only to the person uploading them.
* **Group** — files accessible to members of designated groups. After selecting this option, a menu appears allowing the appropriate groups to be indicated.

The access scope setting applies to the entire batch of files sent in a single operation.

**Note:** The repository does not use folders in the traditional sense. Permissions are assigned to individual files. The access scope can be changed later in the **Sharing** section of the file details panel.

## Processing workflow

Selecting the **Upload** button at the bottom of the panel initiates file uploading. After the upload completes, the platform automatically performs a series of background processes:

* Analyzes the file to enable advanced searching and creates an automatic content summary.
* Identifies the document language.
* Prepares the document for use with the AI Advisor.

Documents appear on the list immediately after uploading; advanced analysis features become available after background processing completes.

## Empty view and error states

* *„File too large"* — the selected file exceeds the 20 MB limit. Reduce the document size or split it into smaller parts.
* *„Unsupported file type"* — an attempt to upload a format other than PDF.
* *„Upload failed"* — connection error during file upload. Retrying is recommended.

## Cloud source import

Import features from **Google Drive** and **Microsoft OneDrive** services are in preparation. The **Sources** entry in the sidebar is currently visible but unavailable — it will be made accessible in a future platform update.
