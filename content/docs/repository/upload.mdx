---
title: Uploading files
description: Adding a controlled batch of files to Repository and assigning its audience.
---

Open **Upload** from the platform controls. The **Upload files** drawer displays the file list and one access setting for the entire batch.

## Supported files and limits

The live upload control accepts PDF, DOCX, XLSX, and CSV files. The displayed maximum is 50 MB per file. A batch can contain at most five files. Workspace storage limits and content validation still apply after the browser accepts the selection.

## Build a batch

1. Drag files onto the drop zone or select **choose file**.
2. Confirm each file name, type, and **pending** status.
3. Remove any unintended item before upload. An item cannot be removed while its status is **uploading**.
4. Set **Access for these files** to **Only me** or selected groups.
5. Select **Add files**.

Files are sent one at a time. Each row changes from **pending** to **uploading**, then **success** or **error**. The drawer closes automatically only when every attempted file succeeds.

## Batch access

One audience applies to all files in the batch. When group access is selected, at least one group is required.

The audience is locked as soon as the first upload attempt starts. This keeps successful files and any retried failures on the same access contract. To upload another set with a different audience, close and reopen the drawer and create a new batch.

## Retry failures

After a partial failure, leave the successful rows unchanged and select **Add files** again. Persate retries rows in **error** or **pending** state. It does not resend rows already marked **success**.

Before retrying, check that the file remains below the displayed limit, the extension and actual content agree, the workspace has storage capacity, the signed-in user still has Repository and selected-group access, and the network connection is stable.

## Background processing

A **success** upload means the original file was accepted and stored. Extraction, summary generation, and search indexing can finish later. Do not repeatedly upload the same file merely because its summary is not yet visible.

## Error states

* **You can upload a maximum of 5 files at a time** — split the selection into separate batches.
* **Choose at least one group, or select Only me** — complete the audience before upload.
* Unsupported file — use PDF, DOCX, XLSX, or CSV and confirm the file is not merely renamed.
* File too large — reduce the file below 50 MB.
* Storage allowance reached — remove unneeded files or contact an administrator.
* **error** after a partial batch — correct the affected file and retry; successful rows are retained.
