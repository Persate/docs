---
title: Browse and manage files
description: Find, preview, share, download, and delete files in Repository.
---

Open **WORKSPACE → Repository** to work with files that you own or that a group has shared with you.

## Find a file

Use the controls above the file list to:

* switch between list and tile view;
* search the visible Repository by file name;
* filter and sort the current result set;
* select one or more files for batch actions.

If **No files found** appears, clear the search and filters before concluding that the Repository is empty. Access is tenant- and group-aware, so another user can see a different result set.

## Preview and inspect

Select a file to open its preview and metadata. The panel can show the original file, processing information, detected language, summary, and access audience when those values are available.

Immediately after upload, processing-dependent fields may still be unavailable. Wait for processing to finish and reopen the file. If the browser cannot preview the format, download the original instead.

## Change access

The file owner or an authorized administrator can change the audience between:

* **Only me**;
* one or more groups in the same organization.

Removing a group removes that group's access; it does not delete the file. A user who belongs to multiple selected groups still keeps access through any remaining group.

## Download

Use **Download** from a file's actions to retrieve the original. To download several files, select them and use the batch download action. Keep the browser tab open until the download starts.

## Delete

Use the file action menu to delete one file, or select multiple files and use the batch delete action. Confirm the dialog carefully: deletion removes the file and its processed data and is not a move to a recycle bin.

Only the owner or an authorized administrator can delete a file. If a shared file must remain available, change its audience instead of deleting it.

## Troubleshooting

* **Preview unavailable** — download the original and confirm that processing has completed.
* **Summary unavailable** — text extraction or summary generation is still running or failed for this file.
* **Action unavailable** — the file is shared with you, but you are not its owner or an authorized administrator.
* **Download failed** — retry after refreshing; if the failure persists, record the file name and contact your administrator.
