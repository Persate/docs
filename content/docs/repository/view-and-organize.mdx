---
title: Browsing and organizing files
description: Working with the document browser, managing metadata, searching, and deleting files.
---

The **Document browser** enables opening, searching, and managing files in the repository.

## Opening files

Selecting a document name in the list view or a tile in the tile view opens the file. The browser displays the document content on the left side and the metadata panel on the right.

PDF documents are displayed using a built-in engine that provides zoom control, page navigation, and an in-file text search function.

## Metadata panel

The sidebar groups document information into several sections:

* **Summary** — an automatically generated summary, visible after document processing completes.
* **Information** — technical properties such as size, modification date, analysis status, and detected language.
* **Visibility** — document visibility management. Allows changing the status between **Private** and **Groups**. Changing permissions does not move the file; it only modifies its visibility scope for other users.
* **Actions** — the **Download** (downloading the file to disk) and **Delete** (removal) buttons located in the top right corner.

## Content search

The **Search field** at the top of the view enables full-text searching across all available documents. The system searches file content, not just file names. Searching can be precisely narrowed using date, size, and status filters.

## Batch operations

In the list view, multiple documents can be selected simultaneously using the checkboxes next to file names. This causes a bottom action bar to appear displaying the number of selected elements. Currently, the only available batch operation is **Delete** — removing the selected files.

## Deleting documents

Files are deleted individually in the metadata panel or in bulk in the list view. Deletion occurs immediately. The platform does not have a recycle bin; files are not retained after deletion and cannot be restored.

**Important:** The deletion operation is irreversible. If a document may be needed in the future, download it before performing this action.

## Empty view and error states

* *"Summary not available yet"* — the document is being processed. The summary will appear automatically after the analysis completes.
* *"Search returned no results"* — no documents match the entered phrase or active filters.
