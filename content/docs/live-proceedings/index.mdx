**Live proceedings** is a module providing access to the official Sejm video channels. The platform enables following broadcasts in real time, analyzing archival recordings, and browsing the calendar of upcoming gatherings (committees, plenary sessions, conferences).

Open the view from **PUBLIC → Recordings** in the sidebar.

## Sub-views

The interface allows switching between three lists:

* **Ongoing** — sessions currently being broadcast live.
* **Previous** — an archive of completed recordings available for analysis.
* **Scheduled** — announced sessions, ordered chronologically by start date.

## Proceeding card

Proceedings are grouped by month. Each is represented by a card containing the session title, start time, and type (**Session**, **Commission**, **Subcommittee**, **Conference**, or **Other**). Icons on the right side of the card indicate the status of analytical processes across two tracks — **Record Analysis** (real-time analysis) and **Enhanced Record** (in-depth analysis). The icon color indicates the state:

* **Blue** — the analysis result is ready.
* **Orange** — analysis is in progress or queued (for in-depth analysis, a progress percentage is displayed).
* **Red** — a server error occurred during analysis.

## Filtering tools

Filters and the search panel, available in the sidebar, allow narrowing the proceedings list:

* **Search** — in session titles.
* **Date range** — restricting the list to a selected time period.
* **Proceeding type** — a multi-select selector for gathering types.

## Empty view and error states

* *"No proceedings found"* — active filters exclude all entries from the list.
* *"Failed to load proceedings"* — server connection error. Refreshing the page is recommended.
