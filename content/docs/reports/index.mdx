---
title: Reports
description: Daily reports summarizing the activity monitored by the platform, available for download.
---

**Reports** provide daily summaries of the activity detected by the platform. Each report covers a single day and can be downloaded for further work.

Access to the module is provided by the **INTELLIGENCE → Reports** entry in the sidebar.

## Report list

Reports are presented in a table, in descending order by date. Each row contains:

* **Type** — the report type icon.
* **Report date** — the day the report covers.
* **Events** — the number of events included in the report.
* **Time saved** — the time estimated to have been saved through automation.
* **Generated** — the moment the report was generated.
* **Download** — the button that downloads the report.

The **Report date** header allows the sort direction to be changed.

## Downloading

A single report is downloaded with the **Download** button in its row. Selecting multiple reports (checkboxes) displays a bottom bar of bulk actions with a **Download** option for the entire selection, as well as **Clear selection**.

## Filtering

A **Date range** selector is available in the sidebar, which narrows the list to the selected period. Shortcuts are also available (including Today, Yesterday, This week, This month, Last 7 days, Last 30 days).

## Empty view states

* *"No reports yet"* — no reports have been generated yet. Daily reports appear once they are generated.
* *"No reports matching filters"* — no report falls within the selected date range. Change the range in the panel on the right.
